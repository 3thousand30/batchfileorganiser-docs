# BatchFile Organiser — Documentation

Official documentation for [BatchFile Organiser](https://3thousand30.com/batchfile-organiser.html), a bulk file organisation tool for Windows by [3thousand30](https://3thousand30.com).

## What is BatchFile Organiser?

BatchFile Organiser sorts, renames, and arranges files in batches on Windows. Detect duplicates, organise by type or date, undo changes if something goes wrong. Fully local — no cloud, no account, no subscription required.

## Key features

- **Batch sort and rename** — organise full folders by type, date, or custom rules
- **Duplicate detection** — find and manage duplicate files
- **Undo support** — reverse changes if needed
- **Multiple organise modes** — flexible rules for different workflows
- **Fully local** — no cloud upload, no account, no telemetry
- **No subscription** — buy once, use forever
- **Built for anyone drowning in messy download folders, photo dumps, or project archives**
